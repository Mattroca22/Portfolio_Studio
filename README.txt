## 📝 ¿Cómo actualizar?

Si quieres hacer cambios:

```bash
# 1. Clonar el repo
git clone https://github.com/Mattroca22/Portfolio_Studio.git

# 2. Instalar dependencias
npm install

# 3. Correr en local
npm run dev

# 4. Hacer cambios, commit y push
git add .
git commit -m "mis cambios"
git push
# Hostinger se actualiza automático 🎉
